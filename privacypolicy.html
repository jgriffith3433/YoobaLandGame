Privacy

Privacy policy

Updated October 19, 2026. This covers yoobalandgame.com and the game opened from Play.

The website

Home, the blog, contact, and this page are ordinary web pages. They do not ask you to make an account. They do not set cookies. The contact form does not save what you type on our server. Send opens your own email app.

Anonymous statistics

Every page of this site, and the game, sends anonymous statistics to Hawkes Analytics, our own statistics service run by Hawkes Gen. It is the only analytics here. No advertising network or outside analytics company gets them.

They show how the site and the game get used: which pages are opened, when Play is pressed, which links lead off the site, how long the game takes to load, how far a walk gets, what Yooba eats, where a fall happens, errors, and how smoothly the game runs. With that comes the kind of device: browser, system, screen size, language, time zone, the graphics chip the game runs on, and the site that sent you here.

No cookies. Your browser keeps a random code in its local storage so a second visit counts as the same visitor. It is not tied to you. Clear site data for yoobalandgame.com and it goes away.

No personal data. Nothing asks for a name, an email address, or an account. If the game asks "Having fun?" or "How was Yooba Land?" and you answer, your rating and any comment you choose to write are sent with the statistics.

No IP address stored. Your IP address is used for a moment to work out the country and city, then thrown away. It is never saved.

The game on your device

Play loads a Unity game in the browser. The first visit downloads the game files. Unity can keep a cache of those files on your device so the next visit starts faster. If you accept the notice shown before play, the game saves that choice in your browser. Both of those stay on your device. Clear site data for yoobalandgame.com in your browser and they go away.

Unity services in the build

The game build includes Unity services for sign-in, lobbies, relay, and voice. If a feature starts one of those, Unity processes the technical data that service needs, such as a player identifier and connection details. That processing is described in Unity's privacy policy.

Email you send

If you use the contact form, the message contains whatever you put in it, including your email address. It is used to reply. It is not added to a mailing list. Ask and that message will be deleted.

What this game does not collect

This site does not collect a VR headset identifier, a phone number, or a payment card. An older version of this page said the game might collect headset identifiers. That does not describe the browser game.

Personal information is not sold.

Children

Yooba Land is a cartoon game. The website does not ask for a name or an account to read it or to press Play. A parent who wants the browser copy removed can clear site data, or write to the contact address.

Changes

If this page changes, the date at the top changes with it.
